자연선택 기반 TD 학습률 선택 시뮬레이터

서로 다른 학습률(α)을 가진 500개 후보 모델을 생성하고, 정해진 갱신 구간마다 평균 RMSE가 최소인 학습률을 선택합니다. 선택한 학습률은 다음 구간의 실제 TD 학습 모델에 적용됩니다.

① 실험 조건

500개 후보 학습률의 하한 (최솟값·중간값·최댓값은 반드시 포함)
상한은 하한보다 커야 합니다.

이 걸음(step) 수마다 후보 모델들의 구간 평균 RMSE를 비교하고 다음 걸음부터 α를 변경합니다. 에피소드 도중에도 갱신됩니다.

용어 주의: 이 시뮬레이터에서 사용자가 ‘시간간격’이라고 부른 값은 TD 업데이트의 학습률 α입니다. 실제 시간 간격과 구별하기 위해 그래프에 학습률로 표시합니다.

첫 구간에서는 학습률 범위의 중간값으로 실제 모델을 학습합니다. 설정한 걸음 수마다 후보 500개의 걸음별 RMSE 평균을 비교하고, 선택된 학습률은 바로 다음 걸음부터 적용합니다. 에피소드 종료 여부와 무관하게 갱신됩니다. 후보 모델 500개는 제거되지 않고 자신의 고정 학습률로 학습을 계속합니다.

③ 갱신 구간별 선택 학습률

가로축: 누적 걸음 수 · 세로축: 학습률 α. 파란선은 해당 구간의 선택값, 주황선은 그 구간에 이미 적용된 값입니다.

④ 선택 적용 모델과 고정 3종 · 시간 기반 감쇠 6종 비교

가로축: 누적 걸음 수 · 세로축: 해당 걸음 구간의 평균 RMSE. 10개 모델 모두 동일한 상태 전이 경로로 학습합니다. 곡선이 많으므로 각 모델을 범례 색으로 구분하세요.

⑤ 유형별 최저 평균 오차 모델 비교

전체 걸음의 RMSE를 평균하여 고정 모델 3개 중 1개, 감쇠 모델 6개 중 1개를 선정합니다. 선택 적용 모델과 함께 세 곡선을 비교합니다.

평가 기준: 전체 학습 걸음에 걸친 RMSE의 평균(구간 길이에 따른 가중평균). 범례를 누르면 해당 곡선이 맨 앞으로 표시되고 다른 곡선은 흐려집니다. 빈 곳을 누르면 해제됩니다. 이 비교는 같은 실험 데이터로 최적 기준 모델을 고른 사후 분석입니다.

⑥ 전체 구간별 비교 기록

실험 설정 및 해석 시 주의사항

환경은 5개 비종료 상태 A~E를 가진 무작위 보행(MRP)입니다. C에서 시작해 매 단계 왼쪽 또는 오른쪽으로 50% 확률로 이동합니다. 왼쪽 끝 도착 시 보상 0, 오른쪽 끝 도착 시 보상 1이며 γ=1, 모든 초기 추정 가치는 0.5입니다. 참 가치함수는 (1/6, 2/6, 3/6, 4/6, 5/6)입니다. RMSE는 한 걸음의 TD 업데이트가 끝날 때마다 계산합니다. 에피소드가 끝나지 않아도 걸음 기준으로 학습률을 갱신합니다.

핵심 한계: 후보 학습률을 선택할 때 참 가치함수를 사용하는 RMSE를 이용하므로, 이는 참값을 아는 실험 환경의 오라클 기반 선택입니다. 실제 환경에서 참값을 모르는 채 동작하는 적응형 알고리즘이라는 증거는 아닙니다. 또한 후보 모델은 처음부터 고정 α로 학습한 반면, 실제 적용 모델은 이전의 추정치를 유지한 채 α만 바꾸므로 선택된 학습률이 실제 모델에 항상 최적이라는 보장은 없습니다. 단일 실행 결과는 우연의 영향을 받습니다.

비교 모델은 고정 학습률 3개(하한·중간·상한)와 시간 기반 감쇠 6개(초기값 3종 × k=0.1, 0.01)입니다. 감쇠 모델은 매 걸음 α(t) = α₀ / (1 + k·t)를 사용합니다. t는 완료한 TD 업데이트 횟수(첫 걸음 t=0)이며 k=0.1 또는 0.01입니다. 학습률의 최솟값 제한을 적용하지 않습니다. 따라서 α₀가 설정 범위의 최솟값이어도 그 아래로 계속 감소하며, 설정한 최솟값·최댓값은 감쇠 모델의 초기 학습률 후보를 정하는 용도로만 사용됩니다. k=0.1은 걸음 수에 비해 매우 빠른 감쇠가 일어날 수 있습니다. 가장 공정한 성능 검증을 위해서는 여러 무작위 시드에서 반복 실험하고 평균과 변동폭을 비교하세요.
